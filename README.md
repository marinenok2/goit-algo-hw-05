Домашнє завдання з Python
У репозиторії зібрано чотири завдання на роботу з функціями, генераторами, файлами та декораторами.
Завдання
1. Кешування чисел Фібоначчі — обчислення чисел зі збереженням попередніх результатів.
2. Генератор чисел із тексту — пошук чисел у тексті та підрахунок їхньої суми.
3. Аналізатор логів — читання файлу, підрахунок записів за рівнями та фільтрація за вибраним рівнем.
4. Бот-помічник — додавання контактів, зміна й пошук номерів, перегляд усіх контактів. Декоратор input_error обробляє ValueError, KeyError та IndexError без завершення роботи бота.
Запуск
Потрібен Python 3. Сторонні бібліотеки не потрібні.
Аналізатор логів:
python task3.py logs.txt
python task3.py logs.txt error
Бот-помічник:
python task4.py
Команди бота: hello, add ім'я телефон, change ім'я телефон, phone ім'я, all, close, exit.
